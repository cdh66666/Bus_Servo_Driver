# Bus Servo Driver

ESP32-C3 SuperMini + DRV8876 + AS5600/MT6701 的飞特 BUS 舵机兼容驱动板固件。

这个仓库的目标是让自制电机驱动板直接挂到飞特单线 BUS 上，被官方
`FT SCServo Debug V1.9.8.6` 上位机当作 HLS 系列舵机使用，支持搜索、编程、
位置控制、速度控制、电流/力矩控制和反馈读取。

## 功能

- 兼容飞特 HLS/SCS 风格数据包：
  `PING`、`READ`、`WRITE`、`REG_WRITE`、`ACTION`、`RESET`、`SYNC_WRITE`
- 官方上位机可搜索到自制板，型号显示为 `HLS3606`
- 支持两块自制板同时挂在同一条 BUS 上：
  - ID2：COM57 桥接板，本身也是一个舵机节点
  - ID3：COM58 从机板，挂在 BUS 上
- 支持一台原厂飞特舵机同时串在 BUS 上用于对比测试，例如 ID1 `HLS3915M`
- 支持位置模式、速度模式、电流/力矩模式、PWM 直驱测试模式
- 支持多圈位置记录，单位为 `4096 count/圈`
- 支持 AS5600 和 MT6701 磁编码器自动识别
- 支持 DRV8876 电流检测和软限流，避免低电流设定下周期性硬停顿
- 支持位置、目标、速度、扭力、电流、电压、温度、移动状态和错误状态反馈
- 提供串口自动测试脚本，不需要用鼠标自动点击官方上位机

## 总线拓扑

实测拓扑如下：

```text
电脑 / FT SCServo Debug
        |
      COM57
        |
ESP32-C3 桥接板，ID2
        |
  单线 BUS DATA
        |
+-------+----------------+
|                        |
原厂飞特舵机 ID1         ESP32-C3 从机板 ID3
```

官方上位机只需要连接 `COM57`。COM57 固件会把电脑侧协议转发到 BUS，同时本板响应 ID2。
COM58 固件只作为 BUS 从机响应 ID3。

## 硬件连接

| ESP32-C3 GPIO | 功能 |
| --- | --- |
| GPIO21 | BUS UART TX |
| GPIO20 | BUS UART RX |
| GPIO1 | DRV8876 EN/IN1，PWM 输出 |
| GPIO2 | DRV8876 PH/IN2，方向输出 |
| GPIO3 | DRV8876 nFAULT 输入 |
| GPIO4 | DRV8876 IPROPI 电流 ADC |
| GPIO8 | 编码器 I2C SDA |
| GPIO9 | 编码器 I2C SCL |

硬件约定：

- BUS DATA 外接 `10k` 上拉
- I2C SDA/SCL 外接 `5k` 上拉
- DRV8876 使用 PH/EN 模式
- DRV8876 VREF 接 `3.3V`
- DRV8876 IPROPI 电阻为 `2.5k`
- 所有 BUS 设备、电机电源、ESP32-C3 必须共地

电流换算按当前原理图：

```text
IPROPI(uA) = ILOAD(A) * 1000
RIPROPI = 2.5k
电流换算约为 0.4 mA / mV
```

## 编码器

固件支持两种 I2C 磁编码器：

| 芯片 | I2C 地址 | 角度寄存器 | 分辨率 |
| --- | ---: | --- | --- |
| MT6701 | `0x06` | `0x03/0x04` | 14 位 |
| AS5600 | `0x36` | `0x0C/0x0D` | 12 位 |

启动时会自动扫描并选择可用编码器。当前测试硬件使用 AS5600。

诊断寄存器：

| 地址 | 内容 |
| ---: | --- |
| 87/88 | 原始角度 |
| 89-92 | 32 位多圈位置，4096 为一圈 |
| 93 | 扫描到的第一个 I2C 地址 |
| 94 | 当前使用的 I2C 地址 |
| 95 | 编码器读取状态 |

## 位置格式

HLS 位置、速度、电流类有符号寄存器使用“符号位 + 幅值”格式，不是二进制补码：

```text
正数: 0x0000..0x7FFF
负数: 0x8000 | abs(value)

例子:
-11   = 0x800B
-7000 = 0x9B58
```

固件对官方上位机暴露的目标位置范围为：

```text
-30000 <= 目标位置 <= 30000
```

这样可以避开 `0x8000/0x7FFF` 边界附近的异常显示。位置模式按“多圈绝对位置”运动，
不会做单圈最短回绕。例如当前位置大于 0、目标为 0 时，只会朝位置减小方向运动；
目标为 `-2` 时会继续减小到 `-2`，不会跳到 `-30000`。

## 控制模式

| 模式 | 功能 | 主要寄存器 |
| ---: | --- | --- |
| 0 | 位置模式 | `42/43` 目标位置，`41` 加速度，`46/47` 速度，`44/45` 电流 |
| 1 | 速度模式 | `46/47` 运行速度 |
| 2 | 电流/力矩模式 | `44/45` 目标电流 |
| 3/4 | PWM 直驱测试 | `44/45` 作为 -1000 到 1000 占空比命令 |

位置模式里，“加速度 / 速度 / 电流”是运动约束：

- 目标位置决定去哪
- 速度决定最快多快
- 加速度决定多快加到这个速度
- 电流决定最多允许用多大力

电流限制是软限流：接近设定电流时连续削弱 PWM，严重过流才硬停保护。

## 编译烧录

安装依赖：

```powershell
pip install platformio pyserial
```

编译：

```powershell
python -m platformio run
```

烧录 COM58 从机板：

```powershell
python -m platformio run -e node_com58 -t upload
```

烧录 COM57 桥接板：

```powershell
python -m platformio run -e bridge_com57 -t upload
```

如果串口号不是 COM57/COM58，修改 [platformio.ini](platformio.ini) 里的
`upload_port` 和 `monitor_port`。

烧录前关闭官方上位机、串口助手和 PlatformIO Monitor，否则串口会被占用。

## 官方上位机复现

1. 打开 `FT SCServo Debug V1.9.8.6`
2. 端口选择 `COM57`
3. 波特率选择 `115200`
4. 校验位选择 `NONE`
5. 点击“打开”
6. 点击“搜索”

实测应出现：

```text
ID 1  HLS3915   # 原厂飞特舵机，如果接在 BUS 上
ID 2  HLS3606   # COM57 自制桥接板
ID 3  HLS3606   # COM58 自制从机板
```

建议先在“编程”页确认参数：

| 参数 | ID2 | ID3 |
| --- | ---: | ---: |
| 相位，地址 18 | 1 | 0 |
| 位置 P/D/I，地址 21/22/23 | 28 / 8 / 0 | 24 / 10 / 0 |
| 最小启动 PWM，地址 24 | 40 | 36 |
| 电流 P/I，地址 34/35 | 18 / 4 | 18 / 4 |
| 速度 P/I，地址 37/39 | 18 / 0 | 14 / 1 |
| 扭矩限制，地址 48/49 | 1000 | 1000 |

基础位置测试：

```text
勾选：扭矩输出
加速度：111
速度：111
电流：100
目标：0、4095、-11、7000、-7000
```

低电流高速测试：

```text
勾选：扭矩输出
加速度：111
速度：1111
电流：90
自动调试：起始 0，结束 4095，延时 2500ms
```

预期现象：

- 输入负目标，例如 `-11`，目标和反馈应显示 `-11`
- 从正位置跨过 0 到负位置，不应跳到 `-3w`
- 低电流高速运行时速度曲线不应周期性突然掉到 0

## 自动测试脚本

脚本直接走飞特串口协议，不操作鼠标：

```powershell
python tools\auto_tune.py --port COM57 --ids 2 3 --apply-best --output tuning_results.json
```

脚本会：

- 检查 ID1/ID2/ID3 通信
- 约 100Hz 采样位置、速度、扭力、电流
- 对 ID2/ID3 运行候选参数并评分
- 默认保持扭矩输出打开
- `--apply-best` 会把最佳参数写回舵机

生成的 JSON/log 是本地调试数据，已通过 `.gitignore` 忽略。

## 已验证项目

当前硬件上已验证：

- FD 官方上位机可搜索 ID1/ID2/ID3
- ID2/ID3 可显示为 `HLS3606`
- 位置目标支持正数、负数、多圈绝对位置
- `-11 = 0x800B` 的 HLS 负数格式解析正确
- `+7000 -> -11` 跨零运动无 `-3w` 跳变
- `0 / 4095 / 8190 / -8190` 往返运动无方向绕路

- AS5600 读数在 0/4095 附近无高低字节撕裂跳变
- 电流反馈和软限流可用

## 常见问题

### 能搜索到，但电机不动

检查：

- 是否勾选“扭矩输出”
- 加速度、速度、电流是否为非零值
- 编码器诊断地址是否为 `0x36` 或 `0x06`
- DRV8876 nFAULT 是否为高电平
- 电机电源和 ESP32-C3 是否共地
- 电机是否接在 DRV8876 OUT1/OUT2

### 输入负目标显示异常

请确认固件已烧录当前版本。HLS 负数必须按 `0x8000 | abs(value)` 解析。
旧版本把它误当作二进制补码，会导致 `-11` 显示成异常大负数。

### 电流设得很小，速度达不到目标

这是正常的。电流是力矩上限，电流太小会主动牺牲速度和到位时间。
